Connection

Zabbix API. Token is only updated if you type a new value.

Lights

Registry of lights / groups used for alerting. Per-severity and per-pattern-step targets pick from this list.

Mute buttons

Press a configured button during an alert to restore Base lighting. Higher severity than the muted level auto-unmutes. Clear while muted plays Recovery → Base. Window 0 on mute timeout = never (minutes).

Audio only

Toggle alert speech and media. Stays off until this button is pressed again. A higher severity does not turn it back on. The press speaks the change even while audio is muted.

Lights only

Sets the strip to Base once, then stops sending light commands so a scene can take over. Stays off until this button is pressed again. No alert colours and no Recovery while it is held.

Audio

Optional sounds via a Home Assistant media_player and/or TTS. Per severity, tick Read Zabbix alert body for Message - Host - Problem; related alerts summarize as Host … along with N others (host strips trailing 6 hex MAC chars only). Mute silences live audio; Test still speaks. Quiet hours skip Info/Warning audio.

Base & Recovery

Base is idle (no problems). When alerts clear, show Recovery, then Base. RGB 0,0,0 turns lights off.

Alert severities

Steady = one colour. Pattern = steps with snap/fade; window 0 loops until cleared or a higher severity wins. Choose which registry lights each severity (and each pattern step) affects.
